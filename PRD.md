# Portfolio product requirements

## Purpose
Help visitors understand Sameer Rajput’s frontend skills, inspect working demos, and start an email conversation. Public site: https://dmndevfolio21.vercel.app/.

## Audience and journeys
- Recruiter: scan the introduction, skills and projects; find GitHub or email.
- Collaborator: explore the visual lab, understand the implementation style, prepare an inquiry.
- Touch or keyboard visitor: reach every control without relying on hover.

## Scope
Preserve the existing portfolio, task demo and contact form. Add a contained interactive lab: image particles, ordered 1-bit dithering, CRT, a datamosh-inspired glitch, flashlight reveal, and portrait/exploded/blueprint/X-ray/cutaway/rotation views. These are stylized 2D studies, not real anatomical imaging or a reconstructed 3D model.

## Acceptance
- All visual treatments work with local assets and no external API.
- Reset returns effects, view, depth, angle and playback to their defaults.
- A pause control and system reduced-motion preference suppress ongoing effects.
- Desktop and 390px mobile layouts have no horizontal overflow.
- Task add/complete/delete, theme switching and navigation remain functional.
- Production build and ESLint pass; browser checks report no application exceptions.
- Metadata, sitemap, robots and structured data use the confirmed public domain.
- Contact clearly prepares an email; never claims to send or retain messages.

## External follow-up
Search Console verification/submission, production Lighthouse measurements, and Google Business Profile eligibility/account setup require owner action. No guaranteed ranking, AI citation, or security certification is promised.
